==================================================
PAYMENT
==================================================

For the initial version, use manual UPI payment.

Do NOT require Razorpay for the first version.

Business UPI ID and QR code should be configurable from Admin Settings.

Checkout should:

1. Create an order
2. Calculate the total server-side
3. Display exact amount
4. Display configured UPI ID
5. Display UPI QR code
6. Allow customer to enter transaction/reference ID
7. Store the transaction ID
8. Mark payment as pending verification
9. Notify/show the customer that payment is awaiting verification

IMPORTANT:

Entering a transaction ID must NEVER automatically mark an order as paid.

Only the authenticated admin can verify the payment.

Create the payment system modularly so Razorpay can be integrated later.
